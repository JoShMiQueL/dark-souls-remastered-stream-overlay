### Installation Section Format
```markdown
## Installation
1. Download `dinput8.dll` below
2. Copy it to your Dark Souls Remastered folder:
   `C:\Program Files (x86)\Steam\steamapps\common\DARK SOULS REMASTERED\`
3. Launch the game — the WebSocket server starts on port 3000
4. (Optional) Create a `dstracker.ini` next to the DLL to change the port

See [README](https://github.com/JoShMiqueL/dark-souls-remastered-stream-overlay/blob/main/README.md) for full usage instructions.

## Verify download

`certutil -hashfile dinput8.dll SHA256`

Compare the output with `SHA256SUMS.txt`.
```

## Writing Style Observations

1. **Use present tense** - "Adds" not "Added"
2. **Be specific** - Include technical details and context
3. **Use backticks** - For code, files, paths, and variables
4. **Emojis for sections** - Consistent emoji usage for section headers
5. **Hierarchical organization** - Main sections with subsections
6. **User-focused first** - Features before technical details
